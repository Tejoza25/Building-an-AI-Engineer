# Day 14 – Refactoring and Publishing an AI Support Chatbot

## 🎯 Objective

The objective of Day 14 was to improve the overall quality of my AI chatbot project by applying clean code principles and preparing it as a professional GitHub portfolio project.

---

# 📖 Overview

Developing AI applications involves more than writing functional code. Professional software should be readable, maintainable, and well documented.

During this task, I refactored my chatbot by improving code organization, simplifying comments, and following consistent coding practices.

- Removed unnecessary debug statements
- Organized imports
- Added descriptive comments

Production-oriented AI Engineering repository tracking an intensive 90-day curriculum focused on **autonomous agents**, **retrieval-augmented generation (RAG)**, and **auditable enterprise LLM pipelines**.

Built using modern LangChain Expression Language (LCEL), local vector databases, dual-branch metadata tracking, and query contextualization.
